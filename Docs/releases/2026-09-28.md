# VerusMetal 0.1.0 — 2026-09-28

First Developer ID signed and notarized public-preview executable for Apple
Silicon on macOS 27 or later. The compiled Metal library is embedded; Xcode is
not required to run the download. Extract the ZIP and run `./verusmetal --help`
from Terminal. This is a command-line executable, not an app bundle.

## Changes

- `--batch-nonces` is the documented batch setting for mining and benchmarking.
  Existing `--batch` commands continue to work; combining both names is an error.
- `devices --json` and `benchmark --json` provide machine-readable output.
  Benchmark JSON rates use hashes per second; terminal output uses MH/s.
- Added `--version`, command-specific `--help`/`-h`, and clearer missing-setting
  diagnostics. Errors now exit with status 2.
- Added a command-line reference, contribution guidance and repeatable release
  packaging. Local configurations and root mining logs are ignored by default.

The hash primitives, 4,096-nonce default, TLS certificate checks and CPU share
verification are unchanged. No new throughput claim is made for this release.

## Validation and artifact

The 16-test unit suite passed, including all 148 independent reference digests
with Metal validation. CLI and local-pool integration passed. The packaged binary
also passed device discovery, independent-vector verification and a small isolated
Metal benchmark. Testing was performed on Apple M4; broader hardware and
long-running stability testing remain outstanding.

Built with Xcode 27.0 (27A266a), Swift 6.4 and Metal compiler 32023.921. Release
settings use Swift `-O` with whole-module optimization, C++ `-O3` with an Apple M1
instruction baseline, and Metal fast math. The arm64-only executable contains
`__TEXT,__metallib`, has no `__DWARF` or source/function debug symbols, and links
only system libraries. Developer ID signing uses Hardened Runtime and a secure
timestamp.
