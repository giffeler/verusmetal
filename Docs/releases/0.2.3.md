# VerusMetal 0.2.3 — 2026-10-03

- Rig names are optional. Without `--worker` or a configured `worker`, the miner
  sends only the wallet address, with no dot or default `m4` suffix. Explicit
  worker names remain supported. Example configurations now omit the worker.
- `--password VALUE` supplies the pool password. Precedence is the CLI option,
  `VERUSMETAL_POOL_PASSWORD`, then `x`. Passwords are not printed or written to
  telemetry; CLI values can still appear in shell history and process arguments.
- CLI help, the command reference and README describe both options.

Focused validation: CLI checks and local-pool integration passed for an explicit
worker with the default password, an unnamed worker with CLI password overriding
the environment, and an unnamed worker with the environment fallback. Checks
verify authorization, share submission, reconnects and password omission from
output and telemetry. Hashing is unchanged; no new performance claim is made.
