# VerusMetal release — 2026-11-11

This release refreshes the optimized production build with Xcode 27.2 and
gekko's organization Developer ID certificate. Mining algorithms, kernels,
scheduling, defaults and CLI behavior are unchanged from the previous public
release. No new performance improvement is claimed. Short smoke benchmarks
establish execution and correctness, not sustained mining throughput.

## Build and validation

Built from `ff81fbf81c76edd2e4522b311baf62e16efec006` using Xcode 27.2 (27B52), Apple Swift 6.4.2
(swiftlang-6.4.2.1.9), macOS 27.2 SDK and Metal 32023.922
(metalfe-32023.922.4). The previously validated production candidate was reused
after its source revision, clean worktree, toolchain and SHA-256 were rechecked.
Production Swift uses `-O` and whole-module optimization without testability.
Metal uses fast math without debug or source-recording flags. The executable
is stripped, arm64-only, embeds `__TEXT,__metallib`, has no `__DWARF` or
source/function debug symbols, and links only system libraries. Signing left
the `__TEXT,__text` and `__TEXT,__metallib` sections byte-for-byte unchanged.

19 unit tests passed with zero failures; CLI and local-pool integration passed. The signed executable passed device discovery, all 148 independent CPU/GPU reference vectors with Metal validation, and an isolated one-second Metal smoke benchmark.

The final ZIP contains exactly one root executable, `verusmetal`, with execute
permissions preserved. Its extracted signature passes strict verification and
`codesign --check-notarization`. Hardened Runtime and Apple's secure timestamp
are present. Apple's notarization log reports `Accepted`, `Ready for distribution`,
no issues, the matching ZIP SHA-256 and the matching executable CDHash.
Gatekeeper reports valid code with its expected bare-command-line-tool message:
"the code is valid but does not seem to be an app". Bare Mach-O executables and
ZIP archives cannot be stapled; their notarization tickets are retrieved online.

Runtime validation covers Apple M4 on macOS 27.2. The deployment target remains
macOS 27; other Apple Silicon GPUs and older supported runtime versions were
not tested in this release.
