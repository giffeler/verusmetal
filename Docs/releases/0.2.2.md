# VerusMetal 0.2.2 — 2026-10-01

- The first measured hashrate appears after about one second of mining. Subsequent
  update delays double (2, 4, 8, 16, ... seconds) up to `--stats-interval`. Reconnects
  restart the sequence. Until a sample exists, the terminal shows `Starting GPU
  search...` with elapsed time. In-flight GPU work or share submission can delay
  a refresh.
- Global `--quiet` suppresses stdout and stderr, including help, JSON and errors.
  Place it before or after the command. Exit codes, JSONL telemetry and the
  loopback API remain available.
- The worker format remains `WALLET.WORKER`. Local integration verifies it in
  authorization and share submission; pool-side display names are outside the CLI.

Validation on Apple M4: all 19 unit tests passed, including a small deterministic
schedule check. Existing CLI and local-pool tests cover nonzero early rates with
`--stats-interval 240`, reconnects, an 80-column terminal, and silent mining with
telemetry and API enabled. No new performance or sustained-pool claim is made.
