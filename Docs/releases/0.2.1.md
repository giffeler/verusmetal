# VerusMetal 0.2.1 — 2026-10-01

Startup now shows GPU preparation, connection, subscription, worker authorization
and waiting for the first job immediately. Terminal wait times refresh every second,
even with a long `--stats-interval`. Redirected output records each phase once.
Reconnects report the retry delay and repeat the connection phases. Mining statistics
appear as soon as an authorized job is available.

The existing 18 unit tests, CLI checks and local-pool integration passed on Apple M4.
The pool check covers both job/authorization orders, reconnects and delayed replies;
an 80-column terminal check verifies waiting updates with `--stats-interval 240`.
Hashing, transport security and telemetry formats are unchanged. No new performance
or sustained-pool claim is made.
