# VerusMetal release — 21 November 2026

VerusMetal 0.2.3 now runs its 19 miner unit tests with Swift Testing. The migration preserves the existing test cases and assertions. The download contains the optimized Apple Silicon executable for macOS 27 or later.

## Validation

All 19 tests passed in the Profile configuration. The packaged executable matched all 148 independent reference vectors on CPU and GPU and completed device discovery and an isolated Metal smoke benchmark. CLI tests and the local pool integration also passed, including reconnect and two CPU-verified shares.

The production build used Xcode 27.2 (27B52), Swift 6.4.2 and Metal 32023.922. Swift used whole-module optimization and Metal used fast math. Runtime checks ran on an Apple M4 with macOS 27.2.1.

The ZIP contains one executable with the Metal library embedded. Strict code signature verification and the online notarization check passed. Apple’s accepted submission records the archive SHA-256 and the executable CDHash shown below.
